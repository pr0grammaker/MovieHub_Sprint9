# 🎬 MovieHub

MovieHub — кинотеатр у вас в браузере!

Это простой API для управления любимыми фильмами. Проект реализован через **TDD (Test Driven Development)**: сначала пишем тесты, потом минимальную реализацию, а затем улучшаем код, не ломая тесты.

---

## 💡 Концепция

Небольшая киностудия решила запустить сервис MovieHub. Основная идея:

- Пользователи могут добавлять фильмы в список ✅
- Получать список фильмов ✅
- Искать фильмы по ID 🔍
- Удалять фильмы из списка ❌

Данные хранятся **в памяти** (база данных пока не нужна). Формат обмена — **JSON**.

Проект небольшой, но практичный: чёткие правила, понятные ответы сервера и реальные HTTP-запросы.

---

## ⚙️ Функциональные возможности API

### 📄 GET /movies
- Возвращает список всех фильмов
- Если фильмов нет — пустой JSON-массив
- Код статуса: `200 OK`

### ➕ POST /movies
- Добавляет фильм
- Тело запроса (JSON):
  ```json
  {
    "title": "Название фильма",
    "year": 2023
  }

- Успешно добавленный фильм: 201 Created
- Ошибки валидации: 422 Unprocessable Entity
- Неправильный Content-Type: 415 Unsupported Media Type

### 🔍 GET /movies/{id}

- Возвращает фильм по ID
- Фильм найден: 200 OK
- Фильм не найден: 404 Not Found
-ID не число: 400 Bad Request

### 🗑️ DELETE /movies/{id}

- Удаляет фильм по ID
- Успешно удалён: 204 No Content
- Фильм не найден: 404 Not Found
- ID не число: 400 Bad Request

### 📆 GET /movies?year=YYYY

- Фильтрует фильмы по году
- Корректный год: 200 OK
- Неверный параметр: 400 Bad Request

### 🛠️ Нефункциональные требования

- Чёткая структура кода (модели, хранилище, сервер)
- Обработка ошибок с корректными кодами ответа
- Тесты на все эндпоинты (успешные и негативные сценарии)
- Все успешные ответы содержат Content-Type: application/json; charset=UTF-8
- Ошибки возвращают объект с полем error и при необходимости details

### 🔄 Подход TDD

Red — пишем тест, который описывает поведение системы, и убеждаемся, что он падает
Green — пишем минимальную реализацию, чтобы тест прошёл
Blue/Refactor — улучшаем код, сохраняя зелёные тесты

Так создаётся надежный сервис с проверенной логикой и «живой документацией» через тесты.
